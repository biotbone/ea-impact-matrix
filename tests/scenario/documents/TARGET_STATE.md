# Fernwood target-state architecture (extract), version 2, November 2025

## Principles
1. Prefer managed services over self-managed infrastructure.
2. Every cloud cost has a named owner (tagging is mandatory).
3. One observability platform for the whole estate.
4. Service credentials use managed identity. Long-lived keys on hosts are not permitted.
5. Close audit findings before optimising for cost.

## Capability map (relevant rows)
- Financial management of cloud
- Enterprise file and content services
- Observability and operations
- Order management
- Customer self-service

## Direction
Retire on-premises server hardware by the end of 2027. Standardise on managed platform services for new and migrated workloads.
